## ⚙️ Instruções de Compilação e Execução (Windows)

* **Pré-requisito:** Compilador GCC instalado (MinGW-w64 ou MSYS2) e disponível no PATH.
* **Dica para acentos no terminal:** Digite `chcp 65001` antes de executar qualquer programa para corrigir a exibição de caracteres especiais (UTF-8).
* **Navegação:** Como as pastas têm espaços no nome, use aspas no caminho. Exemplo: `cd "Aula 03"`.
* **Compilar:** `gcc arquivo.c -o programa.exe -lm` (o `-lm` é necessário quando o código usa `math.h`, como em Bhaskara, distância euclidiana, projétil e `ceil()`).
* **Executar no PowerShell:** `.\programa.exe`
* **Executar no CMD:** `programa.exe`

**Exemplo completo com um exercício real do repositório (Aula 04 - Bhaskara):**

```powershell
chcp 65001
cd "Aula 04"
gcc exercicio01_equacao2grau.c -o bhaskara.exe -lm
.\bhaskara.exe

```
